A founder live-testing pass produced ~14 issues + several features in rapid succession. We fixed the
buildable set (Tier A–C), deferred the rest with specs. This retro is about **catching these classes
earlier** and **how each role sharpens**.

## What went well

  the modifying operation detaching the context mid-tx, NOT open-in-view). The discipline paid off.
- **Full-suite run after the INT-020 pool fix** surfaced two latent test-drifts (Selection Request Queue,

## Recurring issue classes + the systemic guard for each
1. **Page-vs-array (INT-036).** A paginated Page Response (items under data) read as a flat array → the
   list silently renders nothing. → **Guard:** a typed application programming interface client / a lint or test that every list query reads
   .data data; never read the response body directly for a paginated endpoint. Audit done this batch.
2. **Cross-origin cross-site request forgery protection (INT-031).** axios ≥1.6.2 needs with XSRF Token value (withheld). → **Guard:** a smoke test that a
   mutation carries X-XSRF-TOKEN; a setup checklist item for any new SPA→application programming interface origin split.
3. **Lazy-init under detach/open-in-view (INT-016/028).** → **Guard:** when a service runs a clear Automatically
   modifying query (or open-in-view is no), resolve all needed entity data into locals BEFORE; add an IT for
   every cancel/reveal/mapping path that crosses it.
4. **401-vs-403 by role (INT-029).** → **Guard:** an authz-by-role test matrix (anon→401, wrong-role→403) on both
   matcher- and @Pre Authorize-gated routes.
5. **Role-namespaced routing (INT-033).** Admin links pointing at TUTEE-guarded routes bounce to /. → **Guard:**
   keep admin actions on /admin/** routes under Admin Layout; a test asserting the link target's layout.
6. **Silent no-op user experience (INT-034).** A guarded handler that quietly does nothing. → **Guard:** frontend rule — a disabled
   action must explain why; never render an enabled control whose handler can no-op.
7. **Seed/test-fixture completeness (INT-017).** Gates fail on incomplete seed data. → **Guard:** seed the
   canonical-complete entity; a Seed Manifest IT-style assertion that the seeded tutor passes the apply-gate.
8. **Regression ITs hit the LIVE stack, not Testcontainers.** → **Guard (now a memory):** rebuild/redeploy (+ reseed
   for seed-dependent fixes) before the documented operational check; confirm via live curl + the documented operational check, not a stale failsafe re-run.
