## ✓ Worked well (verified live, money + irreversible actions checked)

- **Reject guard is solid.** Reject opens a required Reason\* (6 presets) and **"Confirm Rejection" stays *disabled* until a reason is picked**; enables on selection. Rejected one dummy post — queue count dropped 63→62 cleanly.
- **Approve has a confirm step** ("Approve this post?" → Confirm Approval / Cancel). Approved one tutor listing successfully.
- **Assign-tutor (choose-tutor → assign winner) has an excellent plain-language confirm**: "This will: Mark RGdaebbe as assigned (winner) · Set the job to 'Position filled' · Notify the other applicants · **This can be undone by cancelling the match.**" Assigned one; the 4 sibling selections for that job all cleared at once.
- **Activate-match dialog is strong:** editable hourly rate / sessions / hours with a **live commission preview** — "S$45/hr × 9 sessions × 1.5h = S$608 → **50% = S$304**" — plus an optional commission override. Activated to Live/Unpaid correctly. Commission math is the right 50%-of-first-month and is shown transparently in the table and ledger throughout.
- **Cancel-match confirms and reopens the job:** "This will cancel the match. **The job will reopen for new applicants.**" Cancelled one; clean.
- **Commission-page Mark Paid is the gold-standard confirm** — names amount, tutor, tutee, and says "**This is irreversible.**" (See ADM-01 — the Matching-page version should match this.)
- **Interview scheduling end-to-end works:** the agreed timeslot **auto-fills** the Date & Time, optional meeting-link field accepted, "Interview scheduled successfully." All negotiation states surface with friendly labels (Requested / Awaiting tutor / New times suggested / Tutor declined / Time agreed) under sensible filters (All / Action Required / Scheduled / History). No-Show **is** reachable — Scheduled rows carry Set Link / Complete / **No Show (Tutee)** / **No Show (Tutor)** / Cancel.
- **Analytics inverted-range guard works:** From 2026-12-31 / To 2026-06-22 → alert "End date must be on or after start date." Conversion rate is **≤100% (9.6%)** — the 400% funnel bug is gone.
- **Admin management is clean:** create-admin validation names the bad field ("Enter a valid email"; "At least 8 characters" + "8+ chars, uppercase, number, special"); created a valid admin successfully. **Super-admin protection holds** — Remove is *disabled* for all three Super-admins, enabled for normal admins.
- **User blocking is well-guarded:** Block opens a confirm with a **required Reason\*** dropdown (Policy violation / Spam / Abuse / Fraud / Fake profile / Other), names the user, and explains the consequence + reversibility. Status filter (Active/Blocked) + role + search present.
